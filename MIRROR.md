# This repository is a mirror

The source of truth for `agentdraft-mcp` is the `sdks/mcp` directory of
AgentDraft's application repository, which is private. This repository is
published so the MCP directories — the official registry, Smithery, PulseMCP
and Glama — have a public repo to resolve the server through, and so the
`Repository` link on the PyPI page opens.

Commits here are generated by `sdks/mcp/scripts/sync-mirror.sh`, which
replaces the tracked contents wholesale on each release. **Edits made here are
discarded on the next sync.** Open issues and pull requests are read — a PR
will be applied upstream and land here through the next sync rather than being
merged directly.
